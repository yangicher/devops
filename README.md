# Lesson 5: AWS Infrastructure with Terraform

Цей проєкт розгортає базову інфраструктуру в AWS з використанням Terraform, розділену на модулі.

## Структура проєкту
- **s3-backend**: Створює S3 бакет із версіонуванням та таблицю DynamoDB для блокування стейт-файлів (State Locking).
- **vpc**: Створює мережеву інфраструктуру (1 VPC, 3 публічні та 3 приватні підмережі, IGW, NAT Gateway та таблиці маршрутизації).
- **ecr**: Створює Elastic Container Registry для зберігання Docker-образів з увімкненим скануванням при push.

## Команди для ініціалізації та запуску
- `terraform init` — Ініціалізує робочу директорію Terraform, завантажує необхідні провайдери.
- `terraform plan` — Показує план виконання (які ресурси будуть створені/змінені).
- `terraform apply` — Застосовує зміни та створює ресурси в AWS.
- `terraform destroy` — Видаляє всі створені ресурси.
